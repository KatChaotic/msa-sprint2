## Доработка git-lab-ci

1. Реализованы шаги сборки, тестирования, деплоя и тегирования
    - Тестирование выполнено с использованием скриптов before и after, для корректного запуска и остановки контейнера
    - При тестировании используется имя контейнера, сгенерированное на основе JOB_ID, чтобы не было конфликтов при параллельных пайплайнов

2. Доработаны livenessProbe и readinessProbe параметры для проверки работоспособности подов

3. Созданы параметры для стейдж и прода
    - Для стейджа используется всего 1 реплика и образ помеченный как staging, период проверки работоспособности контейнера уменьшен для снижения нагрузки
    - Для прода используется 3 реплики и образ помеченный как latest
