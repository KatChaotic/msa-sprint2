## 🛠️ Подготовка окружения

1. Выполните в папке первого задания 
```bash
docker compose down
```
Это связано с тем, что необходима пересборка контейнера для задания 2.
И затем поднимите приложение в папке второго задания:
```bash
docker compose up -d --build
```
---

## 🚀 Проверка корректности

В логах приложения должно быть:
```
➡️  BookingService beans:
    - bookingService: class com.hotelio.monolith.service.BookingService
    - grpcBookingService: class com.hotelio.GrpcBookingService
```

При запуске тестов, тесты на booking должны упасть.

## 📦 Порядок миграции данных и доработок сервиса

1. Во время деплоя нового сервиса необходимо смигрировать данные из старой базы данных, поэтому необходимо написать скрипт для переливки данных
2. В сервисе (booking-service) необходимо доработать логику обработки ошибок отправки сообщения в очередь
    - Игнорировать ошибку, чтобы клиент не получал ошибку бронирования в случае, когда не удалось отправить сообщение в очередь
    - Асинхронно отправлять события повторно, реализовать паттерн [Transactional Outbox](https://microservices.io/patterns/data/transactional-outbox.html)
    - Реализовать повторное подключение к Kafka кластеру, сейчас этого не происходит
3. Аналогично доработать повторное подключение к Kafka кластеру в сервисе booking-history-service, если происходит ошибка подключения
